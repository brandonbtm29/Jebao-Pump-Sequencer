# Jebao Pump: Provisioning Reverse Engineering Plan

## 🎯 Objective
Reverse engineer the Wi-Fi provisioning handshake of the Jebao MD-4.4 / Doser 2.4. The ultimate goal is to write a Python script that can broadcast Wi-Fi credentials to factory-reset pumps, eliminating the need to use the smartphone app for bulk deployments (e.g., configuring 50+ pumps for SPE setups).

## 🧠 Context for Mac Antigravity Agent
Hello Mac Agent! 
We successfully built the `jebao_gui.py` application on Windows, which handles *discovery* and *control* of already-provisioned pumps over TCP/UDP. However, the `python-jebao` library does not support the initial Wi-Fi provisioning step. The user is running the iOS "Jebao Aqua" app natively on their Apple Silicon Mac. Your job is to help them capture and reverse engineer the network traffic generated by that app when it links a new pump to the router.

## 🛠️ Step-by-Step Execution Plan

### Phase 1: Environment Setup
1. **Wireshark Installation:** Guide the user to install Wireshark on their Mac (`brew install --cask wireshark` or via website).
2. **Network Interface:** Ensure Wireshark is capturing on the Mac's primary Wi-Fi interface (usually `en0`).
3. **App Setup:** Have the user open the Jebao Aqua iOS app on their Mac and get it ready to the "Add Device" screen.

### Phase 2: Packet Capture (The Heist)
1. Instruct the user to put a Jebao pump into **Pairing Mode** (hold the Wi-Fi button until it flashes).
2. **Start Wireshark Capture.**
3. In the Jebao app, proceed with adding the device, entering the local router's SSID and Password. 
4. The moment the pump's light turns solid green (indicating successful connection), **Stop the Wireshark Capture.**

### Phase 3: Traffic Analysis
1. Export the capture as a `.pcap` or `.pcapng` file.
2. Analyze the capture. Look for:
   - **UDP Broadcasts (SmartConfig/ESPTouch):** The app may have sent thousands of UDP packets with varying lengths to encode the password.
   - **AP Mode Handshake (TCP/UDP):** If the Mac connected directly to the pump's temporary Wi-Fi network (e.g., `Jebao_XYZ`), look for a direct JSON or Hex payload sent to the pump's temporary gateway IP (usually `192.168.4.1`).
3. Extract the payload containing the encoded SSID/Password.

### Phase 4: Python Script Recreation
Once the payload structure is identified, write a standalone Python script (`jebao_provisioner.py`) utilizing the `socket` library to broadcast or send the exact same payload structure, allowing bulk provisioning from the CLI.

> [!TIP]
> **To the Mac Agent:** Jebao devices commonly use Espressif chips (ESP8266/ESP32). It is highly probable that the provisioning method is standard **ESPTouch / SmartConfig**. If you notice a massive flood of UDP packets of varying lengths directed to `255.255.255.255` or multicast addresses, you can likely adapt an existing open-source Python ESPTouch library rather than writing it from scratch!
